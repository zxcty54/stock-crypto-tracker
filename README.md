# stock-crypto-tracker
## Danapur Bazaar marketplace

A separate Flutter Android/web app lives in [`apps/danapur_marketplace`](apps/danapur_marketplace/README.md). It includes reviewed retailer/wholesaler onboarding, private storefront verification, priced product listings, buyer discovery, administrator-controlled mandi rates and a restricted admin panel. Its dedicated workflow delivers one universal APK inside a ZIP directly to Telegram, without GitHub Actions artifacts. See the app configuration and deployment guides before launch. The existing StockPulse app remains unchanged.
